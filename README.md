# Bubbot

Bubbot is a smart desktop companion powered by ESP32 that brings emotions to life through animated faces on an OLED display. With touch interaction and real-time expressions, Bubbot reacts to you, adding fun, personality and warmth to your workspace.

This repository holds the Bubbot web page. The robot's firmware and build guide are in [Bub_bot](https://github.com/Amrittr/Bub_bot).

Static site: plain HTML, CSS and JavaScript, no build step. Open `index.html` in a browser to run it locally. Deployed on Vercel.
